# Sanjai K - Portfolio Website

A modern, high-performance personal portfolio website designed to showcase my experience as an **AWS Certified Solutions Architect & Developer**. This project demonstrates clean code practices, responsive design, and interactive UI elements.

## 🚀 Features

- **Modern UI/UX**: Minimalist design with a focus on typography and whitespace.
- **Dark/Light Mode**: Seamless theme toggling with local storage persistence.
- **Interactive Elements**: Custom cursor, smooth scrolling, and reveal animations.
- **Responsive Design**: Fully optimized for desktop, tablet, and mobile devices.
- **Performance**: Lightweight vanilla JavaScript and CSS for maximum speed.



## 🛠️ Tech Stack

- **Frontend**: HTML5, CSS3 (Variables, Flexbox, Grid), JavaScript (ES6+)
- **Backend (Optional)**: Node.js, Express (for static serving)
- **Deployment**: Compatible with AWS (EC2/S3), Vercel, or Netlify.

## 📂 Project Structure


```
portfolio/
├── index.html      # Main entry point
├── style.css       # Global styles and themes

└── README.md       # Project documentation
```

## 🏃‍♂️ Getting Started

### Option 1: Open Directly
Simply open `index.html` in your web browser to view the static site.

### Option 2: Run with Node.js
If you prefer running it on a local server using the included `app.js`:

1. **Install Dependencies**
   ```bash
   npm install express
   ```

2. **Start Server**
   ```bash
   node app.js
   ```

3. **View**
   Open `http://localhost:8080` in your browser.
